BGM 背景音乐目录
====================

游戏代码会自动循环播放本目录下的 bgm.mp3 作为背景音乐。

当前状态：
  bgm.mp3 已存在（用户提供的《手つかずの感情（未曾经历的感情）》授权副本）。
  点击「开始游戏」后自动起播；🔊/🔇 按钮同时控制音效与音乐。

音量策略（音效比 BGM 大、不被遮住）：
  - BGM 常规音量 0.28（刻意压低，给音效让位）；
  - 合成 / 胜利 / 失败音效峰值约 0.40，明显高于 BGM；
  - 触发音效瞬间对 BGM 做 ducking 临时压到 0.09，约 260ms 后恢复，
    保证音效始终清晰可辨、不被背景音乐盖住。

如需更换曲目：
  直接替换本目录下 bgm.mp3 即可（推荐 MP3 格式）。
  如需其他格式，请同步修改 src/audio.ts 顶部的 BGM_SRC 常量。

版权说明：

  文件缺失或路径错误时，游戏会静默降级（不报错、不阻塞）。
